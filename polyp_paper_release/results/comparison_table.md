## 3. Interpretation guide

- `exp3 - exp5` = **ImageNet 预训练贡献**（同为 timm 骨干 + 颜色增强）
- `exp3 - exp4` = **边界感知损失贡献**（exp4 仅把 w_boundary 0.5→0.0）
- `exp2 - exp1` = **颜色增强贡献**（同为 v1 骨干、随机初始化）
- `exp5 - exp2` = **骨干重设计贡献**（同为随机初始化 + 颜色增强）
- 预期方向：跨域集（CVC-300/ColonDB/ETIS）对增强与预训练最敏感；若 exp4 ≥ exp3（去边界损失反而更好），需检查边界头是否过拟合 ClinicDB 平滑边界，并考虑把边界分支降级为可选模块（见 phase4_ablation_plan.md 预案 B）。
